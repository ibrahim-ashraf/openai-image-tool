# أداة OpenAI للصور

تطبيق سطح مكتب بـ wxPython لإنشاء الصور وتعديلها ووصفها باستخدام OpenAI.

## المتطلبات والتشغيل

1. ثبّت إصدار Python متوافقًا مع wxPython.
2. أنشئ بيئة افتراضية وثبّت الاعتماديات:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

3. شغّل التطبيق:

   ```powershell
   python run_gui.py
   ```

4. عند أول تشغيل، أدخل مفتاح OpenAI من نافذة الإعداد. يمكن إدارة المفتاح لاحقًا من قائمة **إعدادات**.

## المفتاح والخصوصية

- يستخدم التطبيق نموذج **أحضر مفتاحك الخاص (BYOK)**. يحتاج كل مستخدم إلى مفتاح OpenAI خاص به، وتُحاسب طلباته وفق حسابه لدى OpenAI.
- يُخزن المفتاح باستخدام مخزن بيانات الاعتماد للنظام عبر `keyring`، ولا يُكتب في ملفات المشروع أو سجل التكلفة.
- يمكن استخدام متغير البيئة `OPENAI_API_KEY` كخيار متقدم. تكون أولوية المفتاح المحفوظ في مخزن النظام أعلى.
- لا يجري التطبيق طلب تحقق مدفوع عند حفظ المفتاح؛ يظهر أي خطأ في المفتاح عند تنفيذ أول طلب إلى OpenAI.
- تُرسل الصور والتعليمات التي تختارها إلى OpenAI لتنفيذ طلب الإنشاء أو التعديل أو الوصف. تُحفظ الملفات الناتجة وسجل التكلفة محليًا في مجلد المشروع.
- لا ترفع ملفات `.env` أو الصور أو المخرجات أو ملفات البيانات الشخصية إلى GitHub. قواعد `.gitignore` تستبعد هذه المسارات والملفات المحلية المعروفة.
